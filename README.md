# dataviz-2025

Bài tập môn Data Handling & Visualization — FPT University

## Nội dung repo
setup_test.ipynb - Test import 4 thư viện thành công
setup_log.md - Log lỗi gặp phải khi cài đặt môi trường
pandas_cheatsheet.ipynb - Cheat sheet 8+ pandas functions, ví dụ tự đặt
titanic_exploration.ipynb - Phân tích dataset Titanic (4 phần A–D)
learning_log.md - Nhật ký tự học, lỗi gặp, điều mới học được

## Cách chạy
Run code trên VS Code bằng Extension jupyter Notebook

## Môi trường
- Python 3.9
- pandas, numpy, matplotlib, seaborn, jupyter
